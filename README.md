# Autoservice

SaaS для автомоек и автосервисов: мультитенантность, справочники, заказ-наряды, кабинет клиента.

## Стек

- Next.js (App Router) + TypeScript + Tailwind CSS
- Prisma 6 + SQLite для локального демо (схема готова к Postgres: смените `provider` и `DATABASE_URL`)

## Быстрый старт

```bash
cp .env.example .env
npm install
npx prisma migrate dev
npx prisma generate
npm run db:seed
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

После `git pull` ветки с рабочим столом обязательно прогоните миграции и seed — иначе `/owner/desk` упадёт на старой схеме БД.

## Демо-вход (пароль не нужен)

На `/login` выберите роль — ставится cookie `autoservice_demo_user` на 14 дней.

| Email | Роль | Куда попадает |
| --- | --- | --- |
| `owner@demo.local` | Владелец | `/owner` (полный доступ, ЗП, P&L) |
| `admin@demo.local` | Администратор | `/owner` (стол, «Моя смена»: оклад + бонус допродаж; без P&L) |
| `staff@demo.local` | Сотрудник · мойщик (сделка 35%) | `/owner/my-work` |
| `washer@demo.local` | Сотрудник · мойщик (сделка 30%) | `/owner/my-work` |
| `mechanic@demo.local` | Сотрудник · слесарь (оклад) | `/owner/my-work` |
| `client@demo.local` | Клиент | `/client` |

Демо-тенант: **Автомойка Север** (`sever`).

## Что демострировать

1. Войти как **владелец** → **Рабочий стол**, **План выручки**, **Персонал**, **Экономика**.
2. Войти как **администратор** → клиенты, стол, «Моя смена» (оклад + бонус за допродажи после самозаписи). % бонуса настраивает владелец в **Персонал**.
3. Справочники: Клиенты / Авто / Услуги (CRUD).
4. **Заказ-наряды** → статусы (новый → … → закрыт), при заезде «В работе», закрытие с видом оплаты, **Печать**.
5. **Касса** (владелец / администратор) → сводка оплат за день.
6. **Склад** (владелец / администратор) → техжидкости, поступление / расход, инвентаризация; у услуг — норма времени и норма расхода.
7. Войти как **сотрудник** (мойщик/слесарь) → **Моя смена** и **Мой пост**; может поставить «В работе» / закрыть ЗН (опционально автосписание по нормам).
8. Войти как **клиент** → **Запись** (услуга, авто, календарь + плашки времени) → обзор «Мои записи» / **История**; статус «Новая от клиента» сразу у клиента и у админа на графике. Демо `client@demo.local` — 2 авто (Camry, Sportage).

Цена/время по классу авто **не** входят в этот срез.

## Полезные команды

```bash
npm run db:seed    # пересоздать демо-данные
npm run db:reset   # миграции с нуля + seed
npm run build      # production-сборка
```
